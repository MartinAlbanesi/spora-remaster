# Perfil

## Avatar Personalizable (Opcional)
- El avatar reflejará el progreso y logros del usuario en la app.
- Los elementos desbloqueables se obtendrán al completar misiones y desafíos, o alcanzando la cantidad de oxígeno necesaria para desbloquearlos.
- Se podrá visualizar el avatar en el perfil del usuario.
- Se permitirá seleccionar una de las muchas plantillas de avatares existentes, para luego personalizarla a gusto.
- Se podrá elegir entre diferentes estilos de cabello, cara, ojos, ropa, accesorios, fondo del avatar, entre otros.

## Progreso y Avance
- Se mostrará el progreso del usuario en la app, reflejado en la cantidad de misiones y desafíos completados, total de árboles plantados, tiempo en la aplicación, entre otros.
- Se mostrará la cantidad de oxígeno obtenida por el usuario, y la cantidad necesaria para desbloquear objetos de personalización.
- Se mostrará la cantidad de recompensas obtenidas por el usuario, indicando cuántos objetos mágicos ha recolectado.
- Se mostrará la cantidad de insignias obtenidas por el usuario, indicando cuántos objetivos ha completado.
- Se mostrará la cantidad de semillas obtenidas por el usuario, indicando cuántos árboles ha plantado.
